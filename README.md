Physics and quantum mechanics film **beat sheets for review**, organized by descriptive topic. This is a planning-document collection, not a collection of playable or finished videos.

## Collection statistics

- **782 beat sheets** in 782 direct film folders.
- **220 topic groups**: 56 single-entry groups and 164 groups with multiple variants.
- **782 byte-distinct JSON files**; 0 exact byte duplicates.
- **10,373,791 bytes** of beat-sheet content (10.37 MB, excluding manifests and documentation).
- Counts describe this local collection, not distinct completed films or approved uploads. Topic groups include distinct explanations and simulations of related physics concepts.

## What is included

Each film folder contains only `beat_sheet.json`. No MP3, MP4, audio, rendered video, or other production assets are included. Beat sheets may refer to external assets that are not present here. Original source files were not modified.

Multiple versions can cover the same subject while differing in narration, branding, duration, Shorts format, or production instructions. Different file hashes do **not** mean different educational topics. Alphabetical suffixes (`-a`, `-b`, `-c`, etc.) distinguish retained variants; they do not indicate quality, ranking, chronology, or approval. Internal beat-sheet content is preserved, including any original branding or asset references.

This repository contains beat sheets for review. Review and approval are still required before publishing videos. Public availability does not grant a new reuse license; see [source notices](SOURCE-NOTICES.md).
